# Honors Research 2026

## Working Title

**Trajectories of Student–LLM Help-Seeking Across an Undergraduate AI Course: Associations With Subsequent Proctored Assessment Performance**

## Researcher

Saugat Timalsina  
Caldwell University  
Computer Science major, Business Analytics minor

## Project Overview

This Honors Project examines how students' observable help-seeking behavior with large language models changes across an undergraduate Artificial Intelligence course and whether within-student changes are associated with subsequent proctored assessment performance.

The project uses the StudyChat dataset and combines:

- Human-Computer Interaction
- Artificial Intelligence
- Self-Regulated Learning
- Academic Help-Seeking
- Quantitative Longitudinal Analysis

## Research Integrity

This is an observational secondary-data study.

Results will be interpreted as associations rather than causal effects. Observable dialogue behavior will not automatically be treated as evidence of internal cognitive states such as cognitive offloading.
